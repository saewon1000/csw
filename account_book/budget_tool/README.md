# 가계부 웹 앱 (budget_tool)

엑셀 VBA 가계부(`XXXX_가계부.xlsm`)를 파이썬 + Streamlit 웹 앱으로 옮긴 도구입니다.
뱅크샐러드 내보내기 파일(`지출내역/*.xlsx`)을 직접 읽어 월별 가계부·손익계산서·
재무상태표를 계산하고 시각화합니다. **로컬(localhost)에서만 구동**되어 데이터가
외부로 나가지 않습니다.

## 실행

```
run.bat            # 더블클릭 (Windows)
```

또는:

```
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

브라우저에서 자동으로 열리며, 기본 주소는 http://localhost:8501 입니다.

## Python이 없는 PC에서 실행 (git clone → 더블클릭)

Python이 설치되지 않은 Windows PC에서도 **별도 설치 없이** 실행할 수 있습니다.
저장소 상위 폴더(`account_book`)의 **`가계부_실행.bat`** 을 더블클릭하면 됩니다.

### 사용 방법

1. `git clone` 으로 저장소를 받습니다.
2. `account_book\가계부_실행.bat` 을 **더블클릭**합니다.
3. **최초 1회**: 파이썬 런타임(`runtime\`)이 없으므로 자동으로 내려받아 구성합니다.
   (인터넷 필요, 수 분 소요 — 이 준비는 처음 한 번만 진행됩니다.)
4. 준비가 끝나면 브라우저가 자동으로 열립니다. 두 번째 실행부터는 즉시 시작됩니다.
5. 검은 콘솔 창을 닫으면 종료됩니다.

내 거래내역으로 바꾸려면 `지출내역` 폴더에 뱅크샐러드 파일을 넣고 다시 실행하면
자동으로 반영됩니다. 준비 이후에는 인터넷 없이 PC 안에서만 동작합니다.

### 동작 방식 (중복 없는 구조)

- 임베디드 파이썬은 `account_book\runtime\` 에 구성되며, 앱 코드(`budget_tool`)와
  데이터(`지출내역`)를 **복사하지 않고 그대로** 실행합니다. (배포용 사본 폴더 없음)
- 용량이 큰 `runtime\` 은 **Git에 포함되지 않고**(`.gitignore`), clone 후 첫 실행 시
  `setup_runtime.ps1` 이 자동으로 생성합니다.
- 설치되는 패키지 버전은 `requirements.txt` 에 고정되어 어느 PC에서든 동작이 같습니다.

> 이미 Python이 설치된 개발 PC라면 위 `run.bat`(또는 `streamlit run app.py`)으로
> 바로 실행할 수 있으며, 런타임 자동 구성 과정은 필요 없습니다.

## 사용 방법

1. `run.bat`을 실행하면 **지출내역 폴더의 모든 뱅크샐러드 파일을 자동으로 취합**합니다.
   기간이 겹치는 파일들의 거래는 **중복 없이** 합쳐지고, 날짜 기준으로 연도가 정해집니다.
2. 왼쪽 **📑 연도 목차**에서 보고 싶은 연도를 선택합니다. 선택 연도의 원본 파일 목록도
   함께 표시됩니다.
3. **대시보드 / 월별 가계부 / 손익계산서 / 재무상태표 / 연도 추이** 탭에서 분석합니다.
4. **월별 가계부**에서 특정 사용자를 선택하면 하단 **✏️ 거래 편집**에서 해당 월 거래를
   수정/추가/삭제하고 저장할 수 있습니다.
5. **재무상태표** 하단 **✏️ 자산/부채 편집**에서 실제 자산과 다른 값을 직접 보정합니다.

취합 결과는 `data/<년도>/`에 CSV **작업본**으로 저장되며, 편집 내용도 여기에 반영되어
유지됩니다(Git 관리 가능).

### 자동 취합 규칙

- **사용자**: 파일명 접두사(`세원`, `유진`)로 구분하며, `config.json`의 `user_names`로
  표시 이름(`천세원`, `하유진`)에 매핑합니다.
- **중복 제거**: (사용자·날짜·시간·타입·분류·내용·금액·결제수단·메모)가 같은 거래는
  하나로 합칩니다.
- **연도별 재무 스냅샷**: 자산/부채/투자는 시점 정보이므로, 각 연도에 대해 사용자별로
  기준일(파일명 종료일)이 그 연말 이전 중 가장 최신인 파일을 선택합니다.

### 새로고침 / 재동기화

- 사이드바 **🔄 폴더 새로고침**: 지출내역 폴더에 새 파일을 추가했을 때 다시 취합합니다.
- **♻️ 선택 연도 재동기화**: 그 해의 편집 내용을 버리고 폴더에서 다시 만듭니다.

### 연도 통합 추이

`📉 연도 추이` 탭에서 저장된 모든 해의 데이터를 합쳐 월별/연도별 수입·지출·순이익과
순자산 스냅샷 추세를 봅니다.

## 구조

| 파일 | 역할 |
|------|------|
| `banksalad.py` | 뱅크샐러드 xlsx 파서 (거래내역 + 재무현황/투자현황) |
| `ingest.py` | 지출내역 폴더 일괄 취합·중복제거·연도별 스냅샷 선택 |
| `config.py` | 폴더 경로·사용자 이름 매핑(`config.json`), 상대경로 해석 |
| `aggregate.py` | 월별·손익·재무·연도추이 집계 로직 |
| `storage.py` | 작업본 CSV/JSON 저장·로드, 다연도 통합 로드 |
| `app.py` | Streamlit UI (연도 목차 + 5개 탭) |

> 저장소 상위 `account_book\` 에는 Python 미설치 PC용 실행 파일이 있습니다:
> `가계부_실행.bat`(진입점), `setup_runtime.ps1`(런타임 자동 구성), `_freeport.py`(빈 포트 탐색).

## 기존 VBA와의 대응

| VBA | 웹 앱 |
|-----|-------|
| `Load_Expense(월)` | 폴더 자동 취합 + 월별 가계부 탭 |
| `Financal_state` | 재무상태표 탭 (연도별 스냅샷 자동 선택) |
| 손익계산서 시트 | 손익계산서 탭 |
| 월 이동 매크로 | 탭/드롭다운 |
| 설정 탭(년도/경로 수동 입력) | **불필요** — 폴더에서 자동 추론 + 연도 목차 |
| 셀 직접 편집 | ✏️ 거래/자산/부채 편집 + 저장 |
| (없음) | 📉 연도 통합 추이 |
